## Lessons Learned

1. **Ask where the rule lives, not whether it exists.** Name the consumer, then verify the rule
   sits in a file that consumer *reads on the path it walks*. Content audits pass while
   placement fails silently.

2. **Retrofit does not propagate; source does.** Editing N existing homes reaches the agents
   alive today and nothing spawned tomorrow. Put a fleet-wide worker rule at role-creation time.

3. **A delta must come from the identical command run twice.** Pin the expression *and* the
   range, and quote both with the number. Two commands that "measure the same thing" manufacture
   bogus deltas that each look correct in isolation.

4. **To prove something landed where it must, count it in the whole artifact AND in the required
   region, then assert equality.** The region count alone proves presence; only the equality
   proves *absence elsewhere* — and "elsewhere" is the entire failure.

5. **Report a loose instrument even when its output was right.** An instrument wrong while its
   output is wrong gets fixed by anyone; one wrong while its output is right only gets fixed by
   whoever refuses to stop at the answer.

6. **Proximity is not protection.** The three instances today sat one file, one section, and
   eight lines from the rule they violated. Close text reads as already-understood context.
