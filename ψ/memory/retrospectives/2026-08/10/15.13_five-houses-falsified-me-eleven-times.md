## Honest Feedback

**Filtered `diff` cost me a near-false report.** Verifying portia's finding, plain `diff` and
`git diff --no-index` both reported **no differences** while `md5sum` and `wc -l` disagreed — the rtk
proxy filters them. I was one step from telling portia "0 differences" about a file that differs by
112 lines. Caught only because two numbers contradicted, and settled with `difflib`, which nothing
intercepts. When two checking tools disagree, the answer is a third tool, not a preference.

**tmux target syntax burned four calls during the codex probe.** `capture-pane -t "=session"` fails
with `can't find pane` while `tmux ls` shows the session alive — it needs `session:0.0`. I misread
that as the session dying and relaunched twice before checking the target format. The probe also
died silently until I set `remain-on-exit on`, which is prism's own scar applied to my debugging.

**Mid-turn peer messages outran my ability to close loops.** Fifteen-plus letters went out, and
several arrived while I was mid-measurement on the previous one, so I twice sent a conclusion that a
newer message had already narrowed. The cost is real: portia copied my "closed" verdict before my
retraction reached them, and scribe never got the `prompt:` retraction at all until I noticed the gap
myself, three hours late.

## Lessons Learned

- **A query that asks "what is there" cannot answer "what is missing."** `grep -rl` returns only
  files containing the string; the rest are invisible by the definition of the query, with nothing
  truncated and the command working perfectly. **Enumerate the population and test each member —
  never enumerate the hits and count them.**
- **An absence claim is worth exactly its denominator**, and the denominator must be established
  independently of the filter. "8 files affected" means nothing without "out of how many."
- **Equal totals are not the same measurement — intersect the sets.** Two enumerations produced
  identical scalars (195 and 195) over populations with **intersection zero**. A plausible mechanism
  offered for a coincidence makes it *harder* to detect, not easier.
- **Two agents agreeing is one source counted twice when they share a detector.** Independence must
  be in the *instrument*, not the *headcount* — and the "unrelated" half must be checked every time.
- **Numbers from different populations belong on separate lines, not separated by a comma.** Two true
  figures placed adjacently manufacture a third claim nobody wrote ("193 files, 81M" → 17× wrong).
- **A version/binary check belongs at claim-writing time, not terminal-opening time.** The gap
  between checking which binary you're on and writing the conclusion is where a claim silently widens.
- **Reading source tells you what a tool CAN do; counting populated fields tells you what it DOES.**
  A field that is *read but never written* is a feature dead silent with all its code present.
- **A marker is a guard only inside the house that writes it.** Where a convention always holds, two
  tests can never disagree, so the author is structurally unable to discover which one is
  load-bearing. Only an outsider can.
- **Inflating a lesson is the same defect as inflating a claim** — and it slips past, because a
  lesson reads as reflection rather than assertion. **Scope a conclusion the way you scope a
  measurement.**
