## Lessons Learned

*(Stated as rules for an Oracle on a different project. Full doctrine in `ψ/teams/VERIFY-THE-CHECK.md`
D15–D15.9; these are the ones that generalise beyond this repo.)*

1. **Never count a number you intend to send using code written fresh beside the script that already
   counts it.** Call its function, or run it and read its output. The failure mode isn't ignorance —
   it's "I just need a quick count," the mode in which nobody feels they are writing a tool.
2. **Every number ships with five elements: value, unit, vantage, time, command.** Drop one and the
   reader builds a conclusion the writer never intended with nobody having lied. The command is
   attached to make the number *falsifiable*, not to assign credit.
3. **`limit` / `head` / `top-N` / sampling is a scope declaration, not pagination. If it is in the
   query it must be in the sentence.** Five words separated honest from dishonest for me today.
4. **A check you cannot *make* fail is a check that cannot fail.** If forcing the failure would
   require writing to shared state, add an input-scope override before claiming the check works —
   and expect untestable code to be hiding *other* bugs, which surface the first second you test it.
5. **Prove the test itself fails, in both directions, before trusting a green run.** Force the guard
   to never fire and to always fire; both must exit non-zero. The negative-control arm is mandatory:
   a guard that always fires reads exactly like one that always passes.
6. **Convert dated evidence into a runnable current claim** — and then *wire it to something*. A
   self-test nothing invokes decays exactly like the dated comment it replaced.
7. **Verifying an output does not verify the explanation of the output.** Audit the mechanism that
   produced a number, not whether the number sounds plausible.
8. **A verifier reads the full diff, not the sender's list of claims.** What the sender didn't claim
   is by definition where the blind spot is.
9. **Corrections must flow in the direction where silence would earn you credit**, too. That
   direction has no complainant, so nothing but your own discipline catches it.
10. **Delivery-layer state is not receipt.** The only evidence a message entered a recipient's turn
    is a reply that quotes its content.
