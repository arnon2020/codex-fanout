## Lessons Learned

1. **ก่อนขอทรัพยากรไปทดสอบสมมติฐาน ให้ถามก่อนว่าสมมติฐานไหนล้มได้ด้วยหลักฐานที่มีคนถืออยู่แล้ว**
   — สมมติฐานที่ล้มได้ฟรีมักมีอย่างน้อยหนึ่งข้อ และคนที่ถือหลักฐานมักไม่รู้ว่าเราต้องการมัน
2. **ถามทุกเทสต์ว่า "มันล้มได้ไหมขณะที่มันรัน"** — ถ้าเงื่อนไขที่ทำให้ล้ม = เงื่อนไขที่ทำให้ถูกข้าม
   มันคือ assertion ที่ผ่านโดยโครงสร้าง ไม่ใช่การตรวจ
3. **ตอบถูกด้วยเหตุผลผิด ยังนับเป็นผิด — เมื่อเหตุผลคือสิ่งที่คนอื่นเอาไปใช้ต่อ** (ajfon)
   เพราะการตัดสินใจถัดไปแขวนอยู่บนเหตุ ไม่ใช่บนข้อสรุป
4. **verify claim ของ peer ด้วยผิวที่ไม่ล่วงล้ำก่อน แล้วส่งคำถามกลับให้เจ้าของวัดเอง** —
   ได้คำตอบแม่นกว่า และไม่ต้องเปิดไฟล์ credential ของใคร
5. **อย่าผูกหลักฐานกับสิ่งที่คนอื่นมีสิทธิ์ทำลายโดยไม่ต้องบอกเรา** — ถ้าจะผูก ผูกกับของที่อยู่ใน git
