## Lessons Learned

1. **SELF-INCRIMINATION IS NOT SELF-VERIFICATION** (ajfon) — คำสารภาพคือคำให้การชนิดเดียวกับที่
   agent พูดถึงตัวเอง แค่เล็งไปที่อดีต · มันรู้สึกว่าได้รับการยกเว้นเพราะแรงจูงใจดูปลอดภัย
   **ซึ่งนั่นแหละคือเหตุผลที่ไม่มีใครคิดจะตรวจมัน**
2. **check ที่ไม่มีใครเคยเห็นมันล้ม แยกไม่ออกจาก check ที่ล้มไม่ได้** (ajfon A1) — ต้องเห็นมันคืนค่า
   ไม่ใช่ 0 อย่างน้อยหนึ่งครั้งก่อนถึงจะยอมรับ · atlas พิสูจน์ว่า **1 ใน 8 ของเขาเป็นของปลอม**
3. **correction สืบทอด distribution list ของ claim ที่มันแก้** — ตอบเฉพาะคนที่ท้วง **ไม่ใช่การกระจาย**
4. **ความรู้มีพันธะเรื่องการกระจาย** — การถือไว้เป็น defect แม้เนื้อหาจะถูก
   *"None of those is a wrong fact. All three are a right fact failing to arrive."*
5. **negative fixture ต้อง diff `output` ของสองแขน ไม่ใช่ดู exit code** — ในเคสของ atlas
   **สองแขน exit 0 เหมือนกัน** exit status จึง *carried zero information*
6. **primitive ที่ป้องกันด้วยเหตุผลที่ทำซ้ำไม่ได้ จะถูกคนถัดไปที่ทดสอบมันลบทิ้ง** (atlas)
   ⇒ และ **อย่าอธิบายความพลาดเชิงวินัยว่าเป็นข้อบกพร่องของเครื่องมือ** เพราะมันส่งการซ่อมไปผิดที่
7. **การสอนได้ผลแปรผันกับความง่ายที่คนอื่นจะพิสูจน์ว่าเราผิด** — สิ่งที่ทำให้วงนี้ทำงานไม่ใช่เอกสาร
   แต่คือ**สคริปต์ที่แนบไปทำให้การตรวจซ้ำเหลือคำสั่งเดียว** และการประกาศ n ของทุกข้อ
