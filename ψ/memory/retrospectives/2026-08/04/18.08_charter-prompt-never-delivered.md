## Lessons Learned

**1. ฟิลด์ในไฟล์ config ที่ parse ผ่านโดยไม่ error ไม่ได้แปลว่ามันถูกใช้** —
schema ที่ยอมรับฟิลด์ กับโค้ดที่อ่านฟิลด์นั้นไปใช้ เป็นคนละที่กัน และไม่มีอะไรบังคับให้ตรงกัน
ก่อนพึ่งฟิลด์ไหนในสัญญา ให้ `grep` หา **จุดที่อ่านมันไปใช้** ไม่ใช่แค่จุดที่ประกาศมัน
(`prompt:` อยู่ใน `TeamCharterMember122` ครบ · โค้ดที่อ่านไปใช้อยู่คนละกริยา)

**2. เมื่อจะอ้างข้อความระดับ "ทั้ง repo ไม่มี X" การ grep เจาะไฟล์ที่เดาว่าสำคัญไม่พอ** —
และถ้า grep แบบกวาดล้มเพราะ path ผิด **ความล้มนั้นคือหลักฐานว่ายังไม่ได้ตรวจ ไม่ใช่หลักฐานว่าไม่มี**

**3. เอกสารเครื่องมือที่ผูกกับ implementation ต้องระบุว่าเป็นของ implementation ไหน** —
`~/.claude/skills/maw/SKILL.md` อธิบาย prompt delivery ต่อ engine ไว้ละเอียดมาก (system-prompt-file /
AGENTS.md) แต่นั่นคือ maw-js ส่วนของจริงคือ maw-rs ที่ไม่ทำสักอย่าง เอกสารที่ถูกสำหรับของที่ไม่ได้รัน
อันตรายกว่าไม่มีเอกสาร

**4. template ที่บอกให้ "ก๊อปตัวอย่างที่ใช้ได้" ต้องมี valid-if ของตัวอย่างนั้น** —
`volt-codex2.yaml` หายไปจากเครื่อง และ path `codex-setup.ts` ตายไปแล้ว โดยไม่มีอะไรส่งเสียง
