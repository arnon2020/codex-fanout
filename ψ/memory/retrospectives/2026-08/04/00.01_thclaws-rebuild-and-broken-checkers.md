## Lessons Learned

1. **การสารภาพผิดที่ไม่ได้ตรวจ ก็คือ claim ที่ไม่ได้ verify** — และอันตรายกว่า เพราะไม่มีใคร
   สงสัยคนที่ใส่ร้ายตัวเอง · ตรวจก่อนรับผิด เหมือนที่ตรวจก่อนอ้างเครดิต
2. **relay เนื้อหา/หลักฐาน/การวิเคราะห์ได้ · relay "อนุญาต" ไม่ได้** — โดยเฉพาะเมื่อปลายทาง
   ต้องทำสิ่งที่ย้อนยากหรือแตะทรัพยากรกลาง · agent ที่ปฏิเสธอนุญาตแบบ relay กำลังทำงานถูก
   **การหาทางให้มันยอม คือการเอาชนะ gate ที่ทำงานได้**
3. **ตัวตรวจที่มีสตริงเป้าหมายอยู่ในคำสั่งของตัวเอง จะนับตัวเองเสมอ** — `pgrep -f "X"` จาก shell
   ที่ command line มี `X` อยู่ ⇒ ใช้ `/proc/*/exe` หรือ `pgrep -x`
4. **ห้ามทิ้ง stderr ตอนทดสอบว่า "ของขึ้นไหม"** — output คือคำตอบ ไม่ใช่ noise · `exit=0` กับ
   stdin ที่เป็น `/dev/null` แปลว่า TUI จบสวย ไม่ใช่ crash
5. **`pkill -f` บนเครื่องที่มี agent หลายตัว = คำสั่งอันตราย** — ระบุ PID ที่จับมาเอง อย่าจับด้วย pattern
6. **"ghost text" ในกล่อง input ไม่ใช่ข้อความในบัฟเฟอร์** — ทดสอบด้วยการพิมพ์ตัวอักษรเข้าไป
   ถ้ามันแทนที่ทั้งบรรทัด แปลว่ากล่องว่าง · และ **ข้อความที่พิมพ์ตอนมี background shell ค้าง
   จะถูก queue ไม่ใช่ submit** และ queue อาจไม่ flush เลย
