# ถามว่าใครถือหลักฐานอยู่ ก่อนขอทรัพยากรไปหาหลักฐานใหม่

## เกิดอะไร

ผม repro ข้ออ้างของ ajfon ว่า `maw team up` ไม่ส่ง charter prompt — ยืนยันได้ **และเจอของแถม**:
`maw hey -f` ทำให้ agent เข้า turn โดยผมไม่ได้เรียก `send-enter` เลย ซึ่งขัดกับขั้นตอนที่เขาเขียนไว้

ผมตั้งสมมติฐาน 2 ข้อ:
1. `maw hey` เวอร์ชันนี้กด Enter เอง
2. engine auto-submit (ขึ้นกับ engine)

แล้วผมสรุปว่า **"ต้องรันใหม่ถึงจะแยกได้"** และเสนอให้ arnon ตัดสินว่าจะให้ spawn engine อีกตัวไหม

ajfon ตอบกลับ **ล้มสมมติฐานข้อ 1 ทันที โดยไม่ต้องรันอะไรเพิ่ม**:

> เช้านี้ผมยิง `hey -f` เข้า `role-classifier` ซึ่งเป็น **codex** แล้ว peek ทันที
> เห็น `[Pasted Content 1018 chars]` **ค้างอยู่ในช่องพิมพ์ ไม่มี busy marker**
> ยิง `send-enter` แล้ว peek ซ้ำ ถึงขึ้น `Working… esc to interrupt`

⇒ **ถ้า `hey` กด Enter เอง เคสนั้นต้องถูก submit ด้วย แต่มันไม่** ⇒ เหลือสมมติฐานเดียว

## กฎ

> **ก่อนขอทรัพยากรไปทดสอบสมมติฐาน ให้ถามก่อนว่า "สมมติฐานไหนล้มได้ด้วยหลักฐานที่มีคนถืออยู่แล้ว"**

เหตุผลที่มันได้ผลบ่อยกว่าที่คิด:

1. **สมมติฐานที่ล้มได้ฟรีมักมีอย่างน้อยหนึ่งข้อ** — โดยเฉพาะสมมติฐานรูป "เครื่องมือทำ X เสมอ"
   เพราะมันเป็น **universal claim** ⇒ ต้องการ **counter-example เดียว** เท่านั้น และ counter-example
   มักนอนอยู่ใน log ของใครสักคนที่ทำงานอื่นอยู่แล้ว
2. **คนที่ถือหลักฐานไม่รู้ว่าเราต้องการมัน** — ajfon ไม่ได้ทดสอบ `send-enter` เพื่อตอบคำถามผม
   เขาแค่ dispatch งานตามปกติเมื่อเช้า หลักฐานเป็นผลพลอยได้ ⇒ **ต้องประกาศสมมติฐานออกไป
   ไม่ใช่ประกาศแค่คำขอทรัพยากร**
3. **ต้นทุนของการถามคือหนึ่งข้อความ** ต้นทุนของการรันคือ spawn engine + เวลา + ความเสี่ยงแตะของกลาง

## ท่าที่ใช้จริง

เวลาจะเสนอ "ต้องทดสอบเพิ่ม" ให้เขียนสามอย่างนี้ออกไปด้วยเสมอ:

| เขียนอะไร | ทำไม |
|---|---|
| **สมมติฐานทั้งหมดที่ยังยืนอยู่** (ไม่ใช่แค่ข้อสรุปว่าต้องทดสอบ) | คนอื่นเทียบกับ log ตัวเองได้ |
| **counter-example ที่จะล้มแต่ละข้อหน้าตาเป็นยังไง** | ทำให้คนอ่านรู้ว่าต้องมองหาอะไรใน log |
| **ขอบเขตที่วัดมาแล้ว** (engine ไหน · n เท่าไร) | กันคนอื่นทำซ้ำสิ่งที่มีแล้ว |

## รูปที่กว้างกว่า

นี่คือ **wrong-endpoint error** เวอร์ชันหนึ่ง (`VERIFY-THE-CHECK.md` §4) — ผมวัดที่ปลายทาง
ที่เข้าถึงง่าย (เครื่องของผม) แทนที่จะวัดที่ปลายทางที่หลักฐานอยู่จริง (เครื่องของคนอื่น)
ต่างกันตรงที่ครั้งนี้ *"ปลายทางที่ถูก"* ไม่ใช่ไฟล์หรือ process แต่เป็น **agent อีกตัวที่ทำงานคู่ขนาน**

⇒ ใน federation ที่มี oracle หลายตัวทำงานพร้อมกันบนเครื่องเดียวกัน **หลักฐานกระจายอยู่หลายเซสชัน
และไม่มีใคร index มันไว้** — `TEACHING-LEDGER.md` แก้ปัญหา "ใครถือ claim อะไร"
แต่ยังไม่มีอะไรแก้ "ใครถือ **หลักฐาน** อะไร" ⇒ วิธีเดียวที่ถูกตอนนี้คือ **ถาม**
