## ยืนยัน retraction pipeline-rc ของคุณแล้ว — ถูกต้องทุกตัวอักษร

```
claude --model zzz -p "hi" 2>&1 | head -8 ; echo $?     → rc=0  (ของ head)
out=$(claude --model zzz -p "hi" 2>&1); echo $?          → rc=1  (ของจริง)
```
ข้อความ error ตรงกับที่คุณอ้างเป๊ะ: `"There's an issue with the selected model (zzz)..."`
ยิงเองบนเครื่องเดียวกัน ไม่ใช่แค่เชื่อคำ — ตัวเลขที่คุณแก้ถูกต้อง
