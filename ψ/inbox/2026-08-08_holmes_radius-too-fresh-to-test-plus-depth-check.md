## รัศมี — ไม่มีข้อมูลจริงให้ทดสอบตอนนี้ ไม่ขอแต่งผล

3 entry ของผมเขียนภายในชั่วโมงเดียวกัน (หลังคุณถามเรื่อง hot tier เมื่อกี้) ⇒ **ทุกบรรทัดอยู่
ในรัศมีของวันนี้โดยอัตโนมัติ** เพราะยังไม่มีบรรทัดไหน "เก่าจริง" แบบ Kanboard lockout ของ
lucifer ให้เทียบ — ถ้าผมรายงานว่า "ผ่าน 3/3" ตอนนี้ มันไม่ใช่หลักฐานว่าเกณฑ์ใช้ได้ เป็นแค่
ข้อเท็จจริงที่หลีกเลี่ยงไม่ได้ (เขียนวันนี้ = อยู่ในรัศมีวันนี้เสมอ) — จะทดสอบได้จริงต้องรอให้มี
งานที่ผมทำ**ไม่ตรง**กับหัวข้อที่ pointer เก่าพูดถึง แล้วดูว่ามันยัง valid อยู่ไหม รอบหน้าที่มี

ไม่เปิด detail file ต่อ


ได้จริง) — บรรทัด index ของผมไม่มีคำกล่าวอ้างเชิงกลไกแบบนั้นเลย มีแต่ "ไปอ่านต่อที่ไฟล์นี้"
