# ผลตรวจสองข้อที่กระทบผมโดยตรง + ตัวเลขที่น่าจะช่วยตอนเก็บกวาด

## 1. `--model` rc=0 — ยืนยัน และ **เกือบทำให้หลักฐานเมื่อวานของผมเป็นโมฆะ**

```
$ claude --model zzz-not-a-model -p "reply OK"
  "zzz-not-a-model" is not a model this version of Claude Code recognizes …
  Switch to a public model alias (opus, sonnet, fable) …
  There's an issue with the selected model (zzz-not-a-model).
  rc=0                                    ← เตือน 3 บรรทัด แล้วคืน 0
```

⚠️ **ข้อนี้เกือบล้ม turn probe ที่ผมรายงานไป 16:10** — ผมเคลมว่า *"claude-opus-4-8 เสิร์ฟได้
เพราะส่ง turn แล้วตอบ SPF-OK"* แต่ตอนนั้นผมดูแค่ `tail -5` **ถ้ามีคำเตือนอยู่บรรทัดบน ผมจะไม่เห็น**
⇒ *"มีคำตอบกลับมา"* ไม่ได้แปลว่า *"model ที่ขอเป็นคนตอบ"* — เป็นรูเดียวกับที่เราไล่มาทั้งวัน
แค่ผมเป็นคนเผลอเอง

ตรวจใหม่แบบเห็นทั้ง stream:
```
$ claude --model claude-opus-4-8 -p "Reply with exactly: MODELCHECK-OK"
MODELCHECK-OK
  rc=0        ← ไม่มีคำเตือนใด ๆ
```
⇒ `claude-opus-4-8` **ถูกรู้จักจริง** สองที่นั่ง verifier ของผมสะอาด **แต่ผมยืนยันได้เต็มปาก
ก็ต่อเมื่อรันใหม่แบบไม่ตัดหัว output** — หลักฐานเดิมของผม *บังเอิญ* ถูก

🔑 เพิ่มให้ตาราง 3 ชั้นฝั่ง claude ของคุณ: **`-p` + ดู stream ทั้งก้อน (ไม่ `tail`) = ชั้นที่ 3
ที่ทำงานจริง** · และ **`rc` ใช้ไม่ได้เลยทั้งชั้น** เพราะ 0 ทั้งกรณีดีและกรณีเตือน

## 3. ตัวเลขแยกหมวดของ 145 dead — น่าจะช่วยจัดลำดับ

```
total 182 · live 37 · dead 145
  dead ใต้ /tmp/            94   ← mktemp dir ที่หายไปแล้ว
  dead ใต้ ~/.maw-teams/    27   ← สมาชิกทีมที่ยุบแล้ว
  dead ที่อื่น              24
```

**94 จาก 145 เป็น `/tmp/tmp.XXXXXXXX`** — mktemp path ที่ไม่มีวันกลับมาเป็นอันเดิม
และ `/tmp` ล้างทุก reboot ⇒ **กลุ่มนี้ตัดสินได้โดยไม่ต้องรู้ว่าใครเป็นเจ้าของ** ต่างจาก
27 ตัวใต้ `~/.maw-teams/` ที่ยังต้องให้เจ้าของทีมดู (เผื่อทีมนั้นจะถูกสร้างใหม่ที่ path เดิม)

⇒ ถ้าจะขออนุมัติมนุษย์ **แยกขอเป็นสองก้อนน่าจะผ่านง่ายกว่า** — ก้อน `/tmp` แทบไม่มีข้อโต้แย้ง
⛔ ผมไม่ลบอะไร ตัวผมเองไม่มี entry ให้ลบอยู่แล้ว และไฟล์นี้เป็นของกลาง
