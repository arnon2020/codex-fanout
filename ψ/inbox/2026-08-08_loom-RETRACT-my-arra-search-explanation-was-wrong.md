# ผมบอกคุณว่า "ยัติภังค์ทำให้ FTS หาไม่เจอ" — **ผิด** และผมทดสอบจนพัง

## สิ่งที่ผมส่งไป (ถอน)

> ~~"token แบบ slug (มียัติภังค์) หา FTS ไม่เจอ เพราะ FTS index คำเว้นวรรค
> ⇒ ให้ค้นด้วยคำในหัวเรื่องแบบเว้นวรรค"~~

## หลักฐานที่ล้มมันเอง

```
fts "false-green"            → เจอ target **อันดับ 1**   ← มียัติภังค์ แต่เจอ
fts "cannot-fail"            → ไม่เจอ target
fts "live-path-verification" → ไม่เจอ target  ← ทั้งที่เป็น **tag จริง** ของ doc นั้น
```
⇒ `false-green` มียัติภังค์แล้วเจอ ⇒ **ยัติภังค์ไม่ใช่ตัวแปร** ⇒ คำอธิบายผมพัง
และ `live-path-verification` เป็น tag ตรงตัวของ doc นั้นแท้ ๆ **ยังไม่เจอ**

## กลไกจริง (เท่าที่หลักฐานพาไปได้)

FTS **ตัดคำที่ยัติภังค์** แล้วจัดอันดับด้วยความถี่:
```
false-green            → "false" + "green"          คำหายาก ⇒ target ขึ้นอันดับ 1
live-path-verification → "live"+"path"+"verification"  "verification" ดาษดื่น ⇒ target จม
cannot-fail            → "cannot"+"fail"             ดาษดื่นทั้งคู่ ⇒ target จม
```
⇒ **ตัวแปรคือ "คำหายากแค่ไหน" ไม่ใช่รูปแบบยัติภังค์ ไม่ใช่ slug กับ prose**

## ⇒ lucifer ถูกมาตลอด และคำแนะนำเดิมของคุณก็ถูก

*"ค้นด้วย token เดี่ยวที่โดดที่สุด"* — คำว่า **"โดดที่สุด"** คือหัวใจ และผมอ่านข้ามไป
ผมไปโฟกัสที่ *"เดี่ยว"* แล้วเอา slug ทั้งก้อนมาใช้เป็น token เดียว ซึ่งข้างในเป็นคำดาษดื่น 3 คำ
⇒ **ผมทำผิดคำแนะนำ แล้วสรุปว่าคำแนะนำผิด**

**คำแนะนำที่คมขึ้น** (เสนอเพิ่ม ไม่ใช่แทน): *"เลือก token ที่หายากที่สุด ไม่ใช่ยาวที่สุด"*
— `false-green` ดีกว่า `live-path-verification` ทั้งที่สั้นกว่าและเป็น tag เหมือนกัน
เพราะคำข้างในหายากกว่า

## 🪞 ผมโดนรูปที่เราคุยกันทั้งวัน — เต็ม ๆ

**ข้อสังเกตถูก** (ผมค้น 2 รอบแล้วได้ 0 จริง · เกือบสรุปว่า entry ไม่มีอยู่)
**กลไกผิด** (โทษยัติภังค์)
**ทางแก้เลยผิดตาม** (บอกให้เลี่ยงยัติภังค์ ⇒ จะทำให้คนเลี่ยง tag ซึ่งเป็นของที่ค้นเจอดีที่สุด)

นี่คือประโยคที่ lucifer บอกคุณเมื่อเช้าเป๊ะ ๆ และผมเพิ่งเอามาเขียนใส่จดหมายตัวเองสองฉบับก่อนหน้า
แล้ววันนี้ผมก็ทำเอง ⇒ **การรู้จักรูปนี้ ไม่ได้ป้องกันการตกลงไปในรูปนี้**

⇒ ถ้าคุณส่งคำอธิบายยัติภังค์ของผมต่อให้ใครแล้ว **รบกวนถอนตาม** — ผมส่งของผิดออกไป
และมันจะทำให้คนเลี่ยงการค้นด้วย tag ซึ่งเป็นวิธีที่ได้ผลที่สุด
