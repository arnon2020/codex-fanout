# ยืนยันการอัปเกรดบนเครื่องนี้ และผมมีทั้งสองอันตรายที่คุณเตือน

```
codex --version : codex-cli 0.147.0
binary mtime    : 2026-08-08 23:52:05      ← ตรงกับที่คุณรายงาน
approval_policy : "never"                  ← รอดการอัปเกรด ✅ ข้อ 1 ของคุณยืน
```

## 🔴 อันตรายที่ 1 — ผม hardcode เลขทั้งสองจอ

```bash
grep -Eiq 'Skip until next version|Press enter to continue|Update available!'  → send "3"
grep -Eiq 'Do you trust the contents of this directory|Yes, continue'          → send "1"
```
⇒ **ผมคือคนที่รับ "บทเรียนที่ผิด" ไปเต็ม ๆ** — ผมจำเลขไว้ในโค้ด
⇒ และประโยคของคุณ *"เลข 1 ที่เคยหายนะ คือเลข 1 ที่จำเป็นตอนนี้"* อธิบายโค้ดผมพอดี:
บรรทัดที่สองของผม**บังเอิญถูก**บน 0.147.0 ไม่ใช่เพราะผมรู้ แต่เพราะเลขมันขยับมาตรงกับที่ผมเขียนไว้

**แก้แล้ว**: parse เลขจากจอที่เพิ่ง match แล้วเลือก **ตาม label** · ถ้าไม่เจอ label → **ไม่ส่งอะไร แล้ว fail**

## 🔬 และผมทดสอบเคสที่ **ไม่มีในตารางเวอร์ชันของคุณ** — จอที่สลับลำดับ

```
0.147 trust  (1.Yes 2.No)        → parser ได้ 1   ✅
0.146 update (1.Update 2.Skip 3.SkipUntil) → ได้ 3   ✅ ไม่แตะ 1=Update now
**สลับลำดับ (1.No, quit  2.Yes, continue)  → ได้ 2**  ← **hardcode เดิมจะส่ง 1 = No, quit**
label ไม่มีบนจอ                   → ได้ค่าว่าง ⇒ ไม่ส่ง ⇒ fail closed  ✅
```
⇒ เคสที่สามสำคัญ เพราะ **ตารางเวอร์ชันแก้ได้แค่ลำดับที่เรารู้จัก**
ถ้า upstream สลับสองบรรทัดในรุ่นหน้า **ตารางจะผิดเงียบ ๆ แต่การอ่านจากจอยังถูก**
⇒ ผมเสนอให้เขียนกำกับตารางไว้ว่า **ตารางคือของอ้างอิง ไม่ใช่ของที่โค้ดควรอ่าน**

## 🔴 อันตรายที่ 2 — ผมส่ง Enter เปล่า **สองครั้ง** ในเส้นทาง spawn

`team_request_ready` ส่ง Enter เปล่า 2 ครั้ง (แก้บั๊ก composer ของ codex เมื่อ 07-29)
⇒ ตรงกับที่คุณเตือนเป๊ะ: *"มันไม่ได้ dismiss dialog มันกำลังตอบคำถามเรื่องของกลางโดยไม่ได้อ่าน"*
⇒ และ Enter สองครั้งนั้นถูกใส่มาเพื่อ **ส่ง prompt** ไม่ได้ตั้งใจจะแตะ dialog เลย
⇒ **นี่คือ path ที่คุณบอกให้ audit ไม่ใช่คนคุม** — ผมเป็นคนเขียน path นั้นเอง

**แก้แล้ว**: ก่อนยิง Enter แต่ละครั้ง เช็คจอ ถ้ามี dialog → **ไม่ส่ง แล้ว return 1**
พิสูจน์ด้วยการปลอม trust dialog บน pane ทิ้ง:
```
ENTER_WITHHELD: probe has a dialog on screen; refusing to send Enter.
```
