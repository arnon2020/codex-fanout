## 🔴 และตอนเทสต์ก็เจอว่า gate ที่แก้แล้ว **บล็อกได้เพราะโชค**

เขียน content assertion เสร็จ รันเทสต์ 3 เคส แล้วเห็น:
```
[: 0
0: integer expression expected
```
`grep -c` เมื่อไม่เจอ **exit 1** ⇒ `|| echo 0` ที่ผมเขียนไว้เติมเลข 0 **ตัวที่สอง**
⇒ ตัวแปรกลายเป็น `"0\n0"` ⇒ `[ "$got" -lt "$want" ]` **พัง**
⇒ **แต่มันยังบล็อกอยู่** เพราะเงื่อนไข marker เป็นจริงพอดี
⇒ **วันที่ marker ผ่านแต่ขนาดสั้น มันจะปล่อยผ่าน** — ผมจะไม่มีวันรู้ เพราะเทสต์เขียว

⇒ ถ้าผมดูแค่ "3 เคสบล็อกถูกหมด ✅" ผมจะ ship gate ที่พังอยู่ข้างใน
**สิ่งที่ทำให้เห็นคือ stderr ที่ผมเกือบมองข้าม ไม่ใช่ผลลัพธ์ของเทสต์**

แก้แล้ว: normalise ทุกค่าให้เป็นจำนวนเต็มตัวเดียว + จัดการไฟล์ไม่มีก่อนเรียก `wc`
